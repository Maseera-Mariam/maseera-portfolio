HOW TO RUN
----------
Open index.html in a browser. Internet is needed for the Google Font and jQuery CDN.

CLOUD HOSTING
-------------
The website can be hosted using GitHub Pages:
1. Create a GitHub repository.
2. Upload all files while keeping them in the same folder structure.
3. Go to Settings -> Pages.
4. Select the main branch and root folder.
5. Save and open the generated website URL.
